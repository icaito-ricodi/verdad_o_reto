# 🎮 Verdad o Reto Club - App Oficial

¡Bienvenido a la aplicación oficial de **Verdad o Reto Club**! Una herramienta web interactiva y dinámica diseñada para generar desafíos únicos y compartirlos directamente en grupos de Facebook.

## 🚀 Características
- **Seis modos de juego:** Familiar 🟢, Fiesta 🔥, Retos Físicos 💪, Parejas 🌶️, Música 🎵 y Extremo 💀.
- **Enlaces Dinámicos:** Genera URLs únicas codificadas con los datos del creador, el modo y el reto.
- **Diseño Cyberpunk / Gaming:** Interfaz responsiva con estilos de neón optimizados para dispositivos móviles y ordenadores.
- **Acceso directo:** Funciones integradas para copiar al portapapeles y compartir en Facebook con un solo clic.

## 🛠️ Tecnologías utilizadas
- **HTML5:** Estructura semántica de las vistas de la app.
- **CSS3:** Estilos personalizados, variables nativas, animaciones fluidas y diseño responsivo.
- **JavaScript (Vanilla):** Lógica de control de estado de vistas, manejo de portapapeles y lectura dinámica de parámetros mediante `URLSearchParams`.

## 📦 Instalación y uso local
1. Clona este repositorio o descarga los archivos.
2. Abre el archivo `index.html` en tu navegador (se recomienda usar extensiones como *Live Server*).
3. ¡Comienza a crear y compartir tus retos!
